# Clothing Platform — DB Tables (overview)

**Date:** 2026-01-27

## 1) Как получить точный список таблиц на сервере (RU)

```bash
cd /srv/clothing-site
docker compose -f compose.yaml --env-file .env exec -T db psql -U clothing -d clothing -c "\\dt+"
```

## 2) Как посмотреть структуру конкретной таблицы

```bash
docker compose -f compose.yaml --env-file .env exec -T db psql -U clothing -d clothing -c "\\d+ media"
docker compose -f compose.yaml --env-file .env exec -T db psql -U clothing -d clothing -c "\\d+ products"
docker compose -f compose.yaml --env-file .env exec -T db psql -U clothing -d clothing -c "\\d+ ai_jobs"
```

## 3) Ожидаемые “ядровые” таблицы (по текущему стеку)

> Важно: финальный список подтверждаем командой `\\dt+` (выше).

### Доменные
- `users`
- `products`
- `media`
- (возможны) `product_media` (линковочная)
- `ai_jobs`

### Интеграционные/очереди
- (если включено) `outbox_events`
- (если включено) `processed_events` (идемпотентность)

### Системные
- `alembic_version`

## 4) Правила и соглашения (кратко)

- Все изменения схемы делаются через Alembic миграции.
- `id` — UUID.
- Временные поля: `created_at`, `updated_at`.
- `media.object_key` — ключ объекта в MinIO (S3), его используем везде.
