# Docs bundle — 2026-01-27

## Что обновили (последние 5 дней, фокус: AI контур)

### 1) AI Gateway (EU VPS / NL)
- Развернут отдельный сервис **ai-gateway** на сервере **NL50743 (202.148.52.186)**, каталог `/srv/ai-gateway`.
- Публичный домен: `https://ai.voicecrm.online`
- Эндпоинты:
  - `GET /` → `ok` (простая проверка)
  - `GET /health` → `{"ok": true}`
  - `POST /v1/chat/completions` → OpenAI-compatible прокси (auth: `X-AI-Internal-Token`)
- Секрет: `AI_INTERNAL_TOKEN` (64 chars) хранится в `/srv/ai-gateway/.env` и прокидывается в контейнер.

### 2) Clothing-site (prod)
- В `compose.yaml` добавлены переменные AI-контура:
  - `AI_PROVIDER=gateway`
  - `AI_GATEWAY_URL=https://ai.voicecrm.online`
  - `AI_GATEWAY_TIMEOUT_S=60`
  - `AI_INTERNAL_TOKEN=<64 chars>`
- В `apps/api/routes/ai_internal.py`:
  - эндпоинт `/v1/analyze` стал **worker-safe**: авторизация через `X-AI-Internal-Token` вместо JWT
  - поддержан входной формат `bucket/object_key` (приоритетно) + legacy `media_id/job_id`
  - provider переключается через `AI_PROVIDER` (`openai` или `gateway`)
  - для gateway запрос идет в `POST {AI_GATEWAY_URL}/v1/chat/completions`

### 3) End-to-end проверка
- Успешный вызов `POST /v1/analyze` на clothing-api с `bucket/object_key` → ответ `provider=gateway`, модель `gpt-4o-mini`.
